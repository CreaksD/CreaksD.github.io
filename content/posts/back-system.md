我最近在搭建一套自己的「月报 / 财报」系统：每个月，从五个维度来审视自己这个月过得怎么样。

## 五种财富

| 维度 | 含义 |
|------|------|
| 时间财富（Time Wealth） | 这个月的时间花在了哪里，有没有浪费，有没有自由时间 |
| 财务财富（Financial Wealth） | 收入、支出、储蓄，钱有没有变多 |
| 社交财富（Social Wealth） | 和人的连接：家人、朋友、新认识的人 |
| 精神财富（Mental Wealth） | 感受与感悟：学到了什么、体验了什么、情绪状态 |
| 身体财富（Physical Wealth） | 睡眠、运动、健康状态 |

## 月报里塞什么

不只是数字。从情感（感悟）、金钱收入、这段时间在干什么、担心什么、学到了什么——比如学会了「478 呼吸法」、在背 Java 八股文、体验了特斯拉的 FSD 非常震撼……所有这些都可以塞进五种财富里，作为其中一部分的养料。

> 比如「学了 478 呼吸法」→ 身体财富 + 精神财富；「体验了特斯拉 FSD」→ 精神财富 + 时间财富（出行方式变了）。

## 一个附加板块：每日担忧记录

月报之外，还有一个「我担心的事情」的板块，用来**每天记录自己担心的事情**：

- 可以自己添加、编辑、删除
- 按天形成记录，往后翻能按天回看，很清晰
- 目的：**看清自己每天恐惧的来源，让自己没那么焦虑**

关键设计：针对每一个担心的事情，有一个对应的「解决办法」填空——自己写解决办法，可以写多个，也可以为空。

把担忧写下来，再给每个担忧配一个解法（哪怕只是"先放着"），恐惧就会从一团模糊的情绪，变成一个个可处理的条目。这就是这套系统的价值。
